# RetailPro - Proyecto de Data Analytics

## Descripción
RetailPro es un proyecto académico de Data Analytics orientado al análisis de ventas. El repositorio reúne el trabajo realizado a lo largo de los módulos del curso: construcción de base de datos, consultas SQL, proceso ETL, modelado, medidas DAX y documentación.

## Herramientas utilizadas
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Power Query
- Power BI Desktop
- DAX
- GitHub

## Estructura general del repositorio
- Módulo 3: creación y carga de la base de datos.
- Módulo 4: consultas SQL de negocio y métricas.
- Módulo 5: consultas con JOIN, LEFT JOIN y UNION ALL.
- Módulo 6: pipeline ETL en Power Query / Power BI.
- Módulo 7: boceto del dashboard.
- Módulo 8: modelo de relaciones, tabla calendario y medidas DAX.
- Módulo 9: uso de IA para documentación, revisión y análisis crítico.

## Cómo ejecutar los scripts SQL
1. Abrir SQL Server Management Studio.
2. Conectarse a la instancia de Microsoft SQL Server correspondiente.
3. Ejecutar primero el script de creación y carga de la base de datos de M3.
4. Verificar que las tablas y los datos se hayan creado correctamente.
5. Ejecutar después las consultas de negocio de M4.
6. Ejecutar las consultas con JOIN, LEFT JOIN y UNION ALL de M5.
7. Revisar los resultados antes de utilizarlos como fuente de análisis o documentación.

Los scripts fueron desarrollados y probados en Microsoft SQL Server / SSMS. Si una consigna exige otro dialecto SQL, se debe verificar la sintaxis específica antes de reutilizar el código.

## Cómo revisar los archivos de Power BI
Los archivos PBIX documentan el proceso ETL, el modelo de datos, la tabla calendario y las medidas DAX. Para revisarlos se requiere Power BI Desktop.

## Validación de resultados
Los resultados utilizados en los análisis deben poder rastrearse hasta las consultas o transformaciones que los originaron. La IA puede utilizarse como apoyo para redactar, revisar u optimizar, pero las cifras y conclusiones finales deben verificarse contra los datos del proyecto.
